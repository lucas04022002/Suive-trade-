Comment exporter depuis MT5 :
1. Ouvre MT5 → onglet Toolbox (bas de l'écran, Ctrl+T)
2. Clique sur History
3. Clic droit → Save as Report ou Save as Detailed Report
4. Sauvegarde en .htm / .html
5. Ouvre le fichier .htm dans Excel → Fichier → Enregistrer sous → CSV UTF-8

Colonnes attendues : Time, Symbol, Type, Volume, Price, S/L, T/P, Profit
Comment exporter depuis TradingView :
1. Ouvre ton strategy dans TradingView
2. Onglet Strategy Tester en bas
3. Clique sur List of Trades
4. Icône télécharger (export CSV) en haut à droite

Colonnes attendues : Trade #, Type, Signal, Date/Time, Price, Contracts, Profit, Cumulative Profit, Run-up, Drawdown
